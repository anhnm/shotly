1.0.32

Build 33 · Oct 8, 2026

Reliable window capture and smoother macOS 27 performance

This update restores window selection and improves capture responsiveness on the latest macOS release.

  • Fixed Capture Window showing a dark overlay without allowing any window to be selected.
  • Added a customizable Capture Window shortcut in Settings, with ⌘⇧6 as the default.
  • Displayed the active Capture Window shortcut directly in the menu bar panel.
  • Improved hotkey responsiveness and reduced capture stutter on macOS 27.
  • Optimized frozen-screen rendering and multi-display capture using the latest ScreenCaptureKit APIs.
  • Added a safe error message when macOS does not return any selectable windows.

1.0.30

Build 31 · Aug 3, 2026

OCR translation and a more flexible save workflow

This update expands OCR into a complete on-device translation workflow and gives you more control over saving and editor shortcuts.

  • Translate OCR results with automatic source-language detection, side-by-side text, a target-language picker, and one-click copy.
  • Choose the file name and destination when saving from Quick Preview or the Editor.
  • New Automatically Save Captures setting; when disabled, captures go to the clipboard until you save manually.
  • Customize the Copy and Save keyboard shortcuts used in the Editor.
  • Expanded Capture and Recording settings so controls are no longer hidden in a short panel.
  • Renamed Export to Save for clearer, more consistent actions throughout the app.
  • Removed unnecessary Keychain access so Shotly no longer asks for your Mac login password.

1.0.29

Jul 22, 2026

A rebuilt editor with measurement, redaction, and collage tools

A major editor and capture update that introduced a more compact workflow and a broad set of visual tools.

  • Redesigned Editor with a compact top toolbar and context-aware style controls.
  • Added Measure annotations with horizontal and vertical snapping and pixel labels.
  • Added adjustable Blur and Mosaic redaction, Highlight density, and Smart Blur detection.
  • Added Collage Builder with vertical, horizontal, and grid layouts, image reordering, pan, and zoom.
  • Improved multilingual OCR reliability for Vietnamese, Japanese, Korean, and Chinese text.
  • Added watermark presets and a dedicated metadata overlay panel.
  • Improved Quick Preview with clearer actions, multi-preview layouts, pinning, and configurable dismissal.
  • Refined frozen-screen capture, Shotly file naming, appearance handling, and the first-run onboarding flow.
