# Shotly landing page screenshots

Add final product screenshots here using these filenames. The static page detects them automatically and replaces the placeholders without code changes.

- `quick-preview.webp` — multiple Quick Preview cards after consecutive captures
- `editor.webp` — full screenshot editor with toolbar and annotations
- `ocr-smart-blur.webp` — OCR result or Smart Blur example
- `recording.webp` — recording pill and/or video editor
- `menu.webp` — Shotly menu bar popover
- `settings.webp` — Settings window
- `collage.webp` — collage workflow/result
- `watermark.webp` — watermark preset UI or output

Recommended format: WebP, 1600–2200 px wide, under 500 KB per image where possible.
